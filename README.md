# n-body

An n-body simulation running in the browser.

## Build instructions

You'll need [Monopack](https://codeberg.org/noClaps/monopack).

Clone the repository:

```sh
git clone https://codeberg.org/noClaps/nbody.git
cd nbody
```

Build the site:

```sh
monopack src/index.html
```

This will build the site and place the built files in `dist/`
